# R8（令和8年度）酒税法 出題予想と対策

H30・R1・R3〜R7 の7回分の問題と解答例、講本（令和8年度版）、条文をもとにした予想です。予想は過去の出題パターンから組み立てたもので、当たる保証はありません。

---

# 1 まず押さえる前提

## 試験の形式（7回とも同じ）

- 第一問：酒類5つ（イ〜ホ）の種類・品目と判定理由
- 第二問〜第四問：論述。問1は「趣旨」、問2は「具体例・取扱い・手続」
- 第五問：和光酒造株式会社の9月分の納付すべき酒税額の計算
- 試験日は例年11月中旬。第一問の判定日は R5 以降「7月1日現在」と指定されている

## R8 は税率の切り替え前の最後の年

講本 p.35〜37 によると、平成29年度改正の経過措置は令和8年9月30日まで。令和8年10月1日から次のように変わる。

- 発泡性酒類：181,000円 → 155,000円に一本化（発泡酒の155,000円・134,250円の区分がなくなる）
- その他の発泡性酒類：80,000円・「10度未満」→ 100,000円・「11度未満」

R8 の試験は、判定日（7月1日の想定）も第五問の計算月（9月分の想定）も切り替え前になる。したがって、R8 は R5〜R7 と同じ税率・同じ基準で解く可能性が高い。

- 「その他の発泡性酒類」は10度未満で判定する（H30・R1 の解答例は、ちょうど10度を「該当しない」としている）
- 第五問は経過措置の税率（発泡性酒類181,000円、発泡酒155,000円・134,250円、その他の発泡性酒類80,000円）を使う
- 論述で「令和8年10月の税率改正」を問われる可能性もある（改正の趣旨は講本に記載がないので、出ても深追いしない）

# 3 R8 論述の予想

## 本命（どれか1問は出る可能性が高い）

### ① 法定製造数量

- 理由：R1・R3・R5 と奇数年に出ていたが、R7 では出なかった。免許の論点は毎年1問出る
- 想定問題：「法定製造数量の趣旨」と「清酒製造者が単式蒸留焼酎を製造する場合」「焼酎製造者がみりんを製造する場合」「試験のための製造」などの取扱い（法7条3項の別の号に変えてくる可能性）
- 答えの柱（R1・R3 解答例）
  - 問1：最低限度がないと弱小製造者が乱立 → 過度の販売競争で業界が不安定 → 酒税の確保に支障・取締りの手数・品質の保証ができない → 採算の取れる経営規模の者に限って免許を与える
  - 問2：法7条3項の該当号で法定製造数量を適用しない → 原料の利用等で相互に密接な関係があり、主な酒類に制限を付しておけば、従属的な酒類にまで制限を付す必要がない
  - 試験製造（4号）・輸出用清酒（5号）は「主な酒類と従属的な酒類」の理由が使えない。試験製造は真に試験研究目的に限られる（通達 第7条第3項関係）

### ② 製造免許の趣旨・免許を与えない場合（法7条・法10条）

- 理由：H30→R4 と4年間隔。次は R8 にあたる
- 答えの柱（H30・R4 解答例）
  - 問1：高率な税・重要な税収 → 自由にすると経営基礎の薄弱な者・乱立・過当競争 → 酒税の確保が困難 → 不適格者の排除・乱立防止・転嫁を容易に・検査取締り
  - 問2：与えない＝法定製造数量に達しない（法7条2項）／与えないことができる＝免許の取消し歴（法10条1号）など

### ③ 未納税移出（法28条）

- 理由：R4 の1回だけで、輸出免税（R1・R6）と同じ「免除」の章。再出題の間隔（4年）にもあたる
- 答えの柱（R4 解答例）
  - 問1：納税義務は移出時に成立が原則 → 原料用・輸出目的の蔵置・自己の他の製造場への移出は直ちに流通過程に入らない → 二重課税・転嫁前の課税は消費税の本旨に反する → 移出課税の例外として免除
  - 問2：原料用 → 原料とする製造場／輸出業者の輸出用 → 蔵置場／自己の他の製造場・蔵置場（ほかに、おけ売り）
- 変化球：未納税引取（法28条の3）、亡失時の手続（法28条4項：災害その他やむを得ない事情・亡失証明書）

## 対抗

### ④ 酒類製造者と酒類の製造者（法6条・法6条の3）

- 理由：R3→R5 と2年間隔で出ており、R7 も同じ条文（製造場での飲用）。納税義務者の論点は続いている
- 答えの柱（R3 解答例）：酒類製造者＝法7条1項の免許を受けた者／酒類の製造者＝酒類を製造した者の全て（免許の有無を問わない）。みなされる者＝責めに帰することができない飲用の飲用者、移出の移出者（法6条の3第2項・4項）

### ⑤ みなし製造（法43条）

- 理由：R4 の1回だけ。R4 の問1は設問と解答例がかみ合っておらず、出題者が作り直して再出題する可能性がある
- 答えの柱（R4 解答例）
  - 適用されない場合：法43条1項ただし書の各号＋消費の直前の混和（10項）＋ホームリキュール（11項）
  - 水の混和がみなし製造になる場合：製造場以外での加水（5項）。理由は平成18年改正で定額税率の酒類が増え、加水増量による租税回避を防ぐため
  - みなし製造の趣旨：税率差の不当な利得の防止、原料・製造方法による酒類の定義の維持

### ⑥ 法44条（原料用酒類・酒母等の処分禁止）

- 理由：4回出ている最頻出の論点。2年に1回以上のペース
- 答えの柱（R1・H30 解答例）：中間製成物 → 自由な処分・移出は密造を誘発 → 取締りを厳重にし承認制
  - 1項ただし書（原料用酒類）：自己の他の製造場で製造免許を受けている同一品目の酒類の原料とするため、未納税移出で移出する場合
  - 2項ただし書（酒母・もろみ）：法8条各号の者の目的使用、酢の製造、酒母の譲渡
  - 承認なしの処分・移出：その他の醸造酒とみなし、製造者もみなし、直ちに徴収（法58条4項）

## 穴（まだ一度も出ていない論点）

講本で「学習のポイント」に挙がっているのに、7回で一度も出ていない論点。出ても書けるように、講本の該当ページを一度読んでおく。

- 酒税の性格・酒税法の特色（講本 p.7〜8）：生活必需品でなく消費は嗜好と経済力に応じる → 多額で安定した税収／免許制度・種類分類ごとの従量課税・厳格な罰則
- 戻入れ控除と移入酒類の控除（法30条、講本 p.40〜41）：戻入れは課税原因が消滅したことによる控除、移入酒類の再移出控除・原料使用控除は二重課税の防止。第五問の計算で毎年使う
- 納期限の延長（法30条の6、講本 p.43）：期限内申告・担保の提供で1か月以内（引取りは最長2か月）。保全担保（R6）との違い
- 免許の効力（人・場所・物・時、講本 p.32〜33）：相続（法19条）、製造場の移転の許可（法16条）
- 免許を要しない場合（法7条1項ただし書・法9条1項ただし書、講本 p.33〜34）：接客業者に販売業免許が要らない理由
- 密造酒類等の所持禁止（法45条、講本 p.47）
- 記帳・申告・承認・届出の義務と当該職員の権限（講本 p.47〜49）
- 賦課課税になる場合（講本 p.43）

# 4 大問1（種類・品目の判定）の傾向と予想

## 毎年ほぼ決まった「5つの枠」

7回分を並べると、イ〜ホの5問はほぼ次の枠で作られている（順番は年によって入れ替わる）。

- 清酒の枠（6回）：政令物品の重量が米の50%以内か。清酒かすの追加、焼酎の重量計算。H30ハは50%を超えて「その他の醸造酒」
- ビール・発泡酒の枠（7回すべて）：麦芽50%以上・果実香味料5%以下を、物品を加える前と後の2段階で判定
- 果実酒の枠（7回すべて）：糖類の転化糖換算、ブランデー等の10%・90%、15度
- 蒸留酒の枠（7回すべて）：ウイスキー・ブランデーの原酒10%、焼酎と原料用アルコールの度数、留出95度
- 清酒になれない枠（6回）：発芽玄米・麦こうじ・小麦粉など清酒の原料でない物 → その他の醸造酒 → 酒類を加えてリキュール、炭酸水でエキス2度未満ならスピリッツ

## ちょうどの数値（境目）がほぼ毎年出る

- 50%ちょうど（R4ロ・R5イ）→ 清酒になる（「超えない」）
- 5%ちょうど（R3ロ・R4ホ・R5ロ）→ ビールになる
- 10度ちょうど（H30ハ・R1イ）→ その他の発泡性酒類にならない（10度未満の時代）
- 36度ちょうど（H30ニ）→ 連続式蒸留焼酎でも原料用アルコールでもなく、スピリッツ
- エキス分2度ちょうど（R3ニ・R5ニ）→ リキュール（2度未満ならスピリッツ）
- 留出95度ちょうど（R1ロ・R7イ・H30ニ）→ 糖蜜原料でも焼酎から除かれない
- 15度ちょうど（R1ホ）→ 糖類を加えた果実酒にならず甘味果実酒

## R8 の予想

- 5つの枠はそのまま出ると考えてよい
- 果実酒の枠：R6ハ・R3ホ（甘味果実酒）、R7ロ・R5ホ（果実酒）と交互。R8 は甘味果実酒か、R1ホのような「15度ちょうど → 加水で果実酒」の型
- 蒸留酒の枠：ウイスキー（R1・R3・R6）、ブランデー（R4・R5・R7）、焼酎・原料用アルコール（R1・R7）。まだ出ていない「単式蒸留焼酎とスピリッツの境目」「原料用アルコール＋単式蒸留焼酎で45度以下（法43条7項）」が候補
- 清酒の枠：まだ出ていない「アルコール添加の上限（清酒にアルコール等を加えて22度以上・50%超になる場合、法43条1項1号・令50条2項）」や「合成清酒」が候補
- ビールの枠：蜂蜜・果実などで5%をわずかに超える型（R1ニ・R7ホ）か、麦芽比率がちょうど50%の型（R6ホ）
- 判定日が7月1日なら、その他の発泡性酒類は「10度未満」のまま。10度ちょうど・10度台の発泡性の酒類が出たら、種類は醸造酒類・混成酒類などのまま

# 5 第五問（計算）の傾向

R4 の解答例と、R5〜R7・R1・R3・H30 の問題文から読み取れる、毎年ほぼ同じ「特記事項」の型。

- 返品（戻入れ）→ 再移出分は課税標準に入る、戻入控除は移出時の税率（軽減後）で計算、特例税率の200kℓ枠に戻す
- 微生物検査：自社工場内の分析は移出に当たらない／外部（酒類総合研究所）への検体送付は課税
- 見本の無償提供・製造場見学者の試飲：課税（R5 の試飲は製造場内での飲用 → みなし移出）
- 従業員の過失による滅失・破びん：移出に当たらず課税しない
- 不法侵入者の持ち去り（R5）：製造者の責めに帰することができない移出 → 製造者には課税しない（移出した者が製造者とみなされる）
- 食品衛生法・食品表示法による収去：非課税
- 他の製造者から課税移出された酒類の原料使用：原料使用控除
- 特例税率（措法87条・令和5年改正法附則54条）：前年度合計10,000kℓ以下 → 品目ごとに1,300kℓ以下か（1,000kℓ超10%・以下20%、発泡酒は5%・10%）→ 当年度200kℓの残枠
- R8 も9月分なら経過措置の税率（第1章の前提を参照）
