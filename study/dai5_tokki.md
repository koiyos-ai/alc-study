# 大問5 特記事項の解き方まとめ

H29〜R7 の第五問（H29・R1・R3・R4・R5・R7 の問題文、H30・R1・R3・R4 の公式解答例）から、毎年出る「特記事項」を処理別に整理した。各項目に、出題年と解答例での書き方を付けた。

---

# 1 全体の流れ（解答例の型）

1. ① 適用税率：商品ごとに「〇〇酒類（基本／特別）」と書き、境目（10度、21度、37度、麦芽比率など）を理由として書く
2. ② 課税標準数量：「容量×ケース×本数」に、特記事項で課税するものを ②③… として加え、課税しないものは理由と条文を一言書く
3. ③ 酒税額：最初に「全体に共通する判定基準」（特例の適用可否）を書き、商品ごとに【税率特例の判定】【適用枠】【税額計算】
4. ④ 控除：【戻入控除】【原料使用控除】
5. ⑤ 納付税額：（イ）−（ロ）→ 100円未満切捨て
6. 計算は「mℓ×円/kℓ×割合」で書き、1円未満は切捨て

# 2 特記事項の処理一覧

## 課税する（課税標準数量に加える）

### 返品（戻入れ）された酒類を再び課税移出

- 出題：H29（A清酒）、H30（B果実酒）、R1（C清酒）、R3（A清酒）、R4（A清酒）、R5（A清酒）。ほぼ毎年
- 処理
  - ②：再移出分を課税標準数量に加える（再移出も課税移出）
  - ③：戻入分は特例税率が適用されていたことが明らかなので、当年度の特例適用枠に戻す（R3：200kℓ−192kℓ＝8kℓ＋戻入分1.8kℓ＝9.8kℓ）
  - ④：【戻入控除】戻入分×当初移出時の税率×（1−軽減割合）（R3：1,800,000mℓ×110,000円/kℓ×90%）
- R6 以降の新制度（措法87条）：戻入控除は、戻入れ前の当年度酒税累計額の区分に応じた割合で計算（通達 第3編第87条第1項関係4(4)）。当年度酒税累計額からも戻入分の本則税額を引く（同 3注4）
- 移出と戻入れが同じ月（R7）でも、問題文の「9月分の申告書で控除すること」に従い9月分で控除する

### 製造場内での試飲（見学者・社内）

- 出題：H30（A清酒・F スピリッツ）、R1（F スピリッツ 300本）、R3（C発泡酒 1,000本）、R5（C発泡酒 1,000本）、R7（A ビール 4本、試料G 7ℓ）
- 処理：製造場内での飲用 → 移出したものとみなして課税（法6の3①一）
- 解答例の書き方：「見学者が試飲した酒類については移出したものとみなし課税する。（法6の3①一）」

### 外部機関への検体送付（酒類総合研究所）

- 出題：H29（E）、R3（B 12本）、R4（C 20本）、R5（B 20本）、R7（A 15本）
- 処理：製造場から移出したものであるため課税
- R7 は、送付15本のうち4本が返品され製造場内で試飲 → 送付15本は課税、返品4本は戻入控除、試飲4本はみなし移出で再び課税

### 見本の無償提供（料飲店など）

- 出題：H29（B 400本）、R4（B 10,000本）、R7（E 80本）
- 処理：販売促進のための無償提供も移出に該当し課税

### 品評会・鑑評会への出品（国税局への送付）

- 出題：H30（A 30本）、R1（E 30本）
- 処理：課税移出（試飲用を含む）

### その場で混和した試作品（研究開発）

- 出題：R7（試料G：ウイスキー＋炭酸水）
- 処理：みなし製造（法43①）。品目は混和前のまま（法43②）、発泡性・低アルコールなら税率はその他の発泡性酒類。製造場内で試飲 → みなし移出で課税

## 課税しない

### 自社工場内での分析・官能検査

- 出題：H29（E 20本）、H30（F）、R3（B 20本）、R4（C 20本）
- 処理：飲用に供していないため移出したものとみなされず、課税しない
- H30 解答例：官能検査に使用したものも課税しない（法46関係通達7-(2)ホ、実務上）

### 従業員の過失による破びん・流出・滅失

- 出題：H29（C 400本）、R3（D 400本）、R4（D 200ℓ）、R5（D 400本）
- 処理：製造場内での破損は移出に該当しないため課税しない

### 不法侵入者による持ち去り（盗難）

- 出題：H30（D）、R1（D 100本）、R3（D 100本）、R5（D 100本）
- 処理：製造者の責めに帰すべき事由がないため、製造者には課税しない（法6の3④：移出した者が製造者とみなされる）

### 法律に基づく収去

- 出題：H29（D 食品衛生法）、R1（A 食品表示法）、R3（E 薬機法）、R4（E 食品衛生法）、R5（E 食品表示法）、R7（D 食品表示法）
- 処理：収去酒類等の非課税（法6の4）
- 解答例の条文表記：R1「法6の4三」（食品表示法）、R3「法6の4二」（薬機法）。収去の根拠法で号が変わる

### 税務職員の質問検査（見本採取）

- 出題：H30（C）
- 処理：質問検査による移出は課税しない（講本 p.29 参考：当該職員の見本採取は納税義務者・申告の規定を適用しない、通則法74の4②、酒法30の7）

### 輸出目的の移出

- 出題：R7（D 200本）
- 処理：輸出免税（法29①）で課税標準数量から除く

### 在日大使館への送付

- 出題：R7（F 30本）
- 処理：免税として課税しない（ユーザー確認済み。条文上の根拠は未確認）

## 控除する

### 原料使用控除（他の製造者から課税移出された酒類を原料に使用）

- 出題：H29（F 果実酒）、H30（E 甘味果実酒）、R1（B スピリッツ 4仕込）、R3（F 果実酒 4,000ℓ）、R4（F ブランデー 400ℓ）、R5（F 果実酒 5,000ℓ）、R7（C ブランデー 10ℓ）
- 処理：使用量×原料酒類の税率（移出元が特例の適用を受けていなければ本則税率）
- 仕込数に注意：R1 は「200ℓ×4仕込み＝800ℓ」
- 原料酒類の税率を自分で判定する（R4 ブランデー45度：370,000＋（45−37）×10,000＝450,000円、R7 ブランデー40度：400,000円）
- R7：移出元が特定大法人 → 措法87条の適用なし → 本則税率で控除

# 3 税率の判定で毎年問われる境目

- 10度ちょうど（R3 B単式蒸留焼酎・C発泡酒）：発泡性があっても「その他の発泡性酒類」（10度未満）に当たらず基本税率。発泡酒も10度以上は基本税率で、特例（措法87条旧制度）の対象外
- 麦芽比率：ホップを分母に含めて計算する（H30 D 48.4%、R3 C 24%、R4 B 30%、R7 E 48.5%）
- 新ジャンル：糖類・ホップ・水・大豆たんぱく質分解物・酵母エキス（R3 E、R4 E）
- 低アルコールの蒸留酒類（措法87の2）：発泡性なし・13度未満なら 80,000＋（度数−8）×10,000（H30 C ウイスキー11度＝110,000円）
- ウイスキー・ブランデー・スピリッツ：37度未満 370,000円、以上は1度ごとに加算（R7 F 39度＝390,000円）
- 甘味果実酒・リキュール：13度以上は 120,000＋（度数−12）×10,000（R1・R4 F 17度＝170,000円、R3 F 14度＝140,000円、H30 E 21度＝210,000円）

# 4 税率の特例（中小製造者の軽減）

## H29〜R5（旧制度：措法87条・令和5年改正法附則54条）

1. 前年度の課税移出数量の合計が10,000kℓ以下か
2. 品目ごとに前年度1,300kℓ以下か（1,000kℓ超は上段、以下は下段の軽減割合）
3. 当年度200kℓの残枠（200kℓ−4〜8月の移出数量＋戻入分）
4. 枠内は軽減後、枠を超えた分は本則
- 対象は清酒・焼酎・果実酒（その他の発泡性酒類のみ）・合成清酒・発泡酒。10度以上の発泡酒は対象外（R3）

## R6〜（新制度：措法87条、承認酒類製造者）

1. 承認酒類製造者で、前年度の総課税移出数量が3,000kℓ以下か
2. いずれか一の品目の前年度数量（最大のもの）で列を決める（400kℓ以下／400kℓ超1,000kℓ以下／1,000kℓ超1,300kℓ以下／1,300kℓ超）
3. 当年度酒税累計額（本則税額の累計）で行を決める（5,000万円以下／8,000万円以下／1億円以下）
4. 品目を問わず、製造免許を受けた品目の全商品に軽減割合を適用（R7：400kℓ超1,000kℓ以下・5,000万円以下 → 15%）
- 答案：③本則税額、④酒税額（本則×割合）を分けて書く
